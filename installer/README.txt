MoxyVPN

1) Open MoxyVPN (Desktop / Start menu). Windows asks for Administrator - needed for the
   whole-system tunnel.
2) Sign in with your own Firefox / Mozilla VPN account (email + password).
   Your password is sent only to Firefox Accounts and is not saved.
3) It connects automatically. Closing the window keeps it in the system tray (fox icon).
4) Data usage is read from your account and remembered between runs.

Menu (the three lines, top right) opens Settings: theme, verify exit location, encrypted DNS,
proxy-only mode, local address/port, HTTP proxy, split tunneling, custom edge, upstream proxy,
logs, account and sign out.

Chrome extension: see the "extension" folder (Start menu > MoxyVPN > Chrome extension folder).
Open chrome://extensions, enable Developer mode, "Load unpacked" and pick that folder.

Python is bundled - nothing else to install.
