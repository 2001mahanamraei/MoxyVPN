# MoxyVPN browser extension (Chrome / Edge / Brave, Manifest V3)

Sends the browser through the MoxyVPN desktop app (SOCKS5 `127.0.0.1:<port>`), shows the exit country
and data usage, and lets you choose all sites or selected sites. It needs the desktop app: see
`../docs/ARCHITECTURE.md` for why it cannot be standalone.

Install: `chrome://extensions` -> Developer mode -> Load unpacked -> this folder.
